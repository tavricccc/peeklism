# Peeklism 0.6.0

空白鍵仍是快速預覽；使用「開啟檔案 → Peeklism」、預覽中的「完整查看」或系統匣選單，可開啟獨立的唯讀查看器。

## 新增

- 圖片以原始解析度解碼，支援 100% 實體像素、縮放、拖移、旋轉與 SVG。
- 影片／音訊支援播放控制、進度、音量、倍速、循環與全螢幕。
- PDF 改用 WebView2 完整閱讀器，支援所有頁面、跳頁、搜尋、文字選取與列印，不受預覽的 25 頁限制。
- Markdown 使用 Markdig 解析，支援表格、巢狀清單、工作清單、本機圖片與原始碼切換。
- 文字讀取不再沿用預覽的 256 KB 截斷，支援 UTF-8 與帶 BOM 的 Unicode。
- 查看器支援拖放、多選、同類檔案切換、快捷鍵與多視窗。
- 安裝時加入 Windows「開啟檔案」清單，不變更預設程式；解除安裝時清理 Peeklism 的關聯。

## 修正

- 關閉或切換預覽時釋放影音資源，停止已取消的 PDF 預覽渲染。
- 分別重建共用版與自帶版的 WinUI PRI 資源，避免增量打包造成自帶版無法啟動。

## 安裝與限制

下載下方 `Peeklism.Setup.exe`；`SHA256SUMS.txt` 可用來比對下載檔案。支援 Windows 11 build 26100 以上、x64。安裝檔尚未簽章。

PDF／文件需要 Microsoft Edge WebView2 Runtime，安裝包不另外攜帶此元件。HEIC、AVIF、HEVC 等格式取決於 Windows 已安裝的解碼器。

Markdown 不執行 HTML、JavaScript 或 MDX 元件，不載入遠端圖片；外部連結需確認。本機圖片限於文件資料夾內。文字上限 64 MiB，點陣圖上限 1.6 億像素；超限會顯示錯誤，不假裝已讀取完整內容。

## 驗證

46 個自動化測試通過。共用版與自帶版均從最終安裝包解出、核對 manifest 雜湊，並驗證查看器啟動與正常關閉。
